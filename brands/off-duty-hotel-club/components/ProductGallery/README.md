# ProductGallery

The product page's images: the back as the main image, the front second.

- The consumer provides: the images in order (back, front, any details) with alt text.
- Main image is 4:5 on `stone`. Thumbnails sit in a column to the left on desktop and in a row beneath below the laptop breakpoint, each 4:5 and at least `tap-target` wide.
- The selected thumbnail gets a 1px `ink` ring; others sit at reduced opacity and come up on hover.
- Changing image fades over `duration-slow`. No zoom lens, no carousel arrows, no autoplay.
