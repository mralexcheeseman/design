# EmptyState

What a page or drawer shows when there is nothing in it: an empty bag, no saved shirts, no search results, a missing page.

- The consumer provides: an optional `label`, a one-line `title`, one sentence and one TextLink.
- Centred, with generous space above and below. No illustration, icon or emoji.
- Copy stays in the voice: "Your bag is empty." / "Nothing saved yet." / "This room doesn't exist."
