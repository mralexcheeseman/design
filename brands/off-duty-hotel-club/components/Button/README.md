# Button

The one solid button: an `ink` block with `paper` text, square corners, 52px tall.

- Markup: `<button class="odh-button">Add to bag</button>`. Add `block` for full width (product page, bag) and `paper` on a photo or `staff-green`.
- Use one per view, for the primary action: Add to bag, Explore the collection, Checkout. Every other action is a TextLink.
- The label is a sentence-case verb phrase. A single → may follow "Add to bag" and nothing else.
- Hover darkens slowly to `ink-2`. It never lifts, glows or changes size.
