# TextLink

A call to action written as an uppercase `label` with a 1px underline: the house style for every secondary action.

- Markup: `<a class="odh-link" href="…"><span>Shop all four</span></a>`.
- Use it for section links ("Shop all four", "The hotels"), the editorial CTA and "Clear filters".
- No arrow icons. The underline is the affordance; on hover the underline clears.
- Two or three words. The target is at least 44px tall.
