# SectionHeading

A section's title with an optional line and a TextLink, on one baseline.

- The consumer provides: the title, an optional line and an optional link.
- Title is `headline`: roman, one line, no full stop, no italic second line. The line is `body` in `ink-2`; the link is a TextLink aligned right.
- `space-6` below it before the content. On phones it stacks: title, line, link.
