# SearchDrawer

Search across shirts, hotels and places, in a drawer.

- The consumer provides: the query, the results and the result count.
- An underline input in `title` size with a 20px search icon; the result count in `body-sm` `ink-3` below.
- Results are rows on `line` hairlines: a 4:5 thumbnail, the role in the serif, and "Hotel · Place" in `body-sm`.
- Search matches the role, the hotel name and the place, so "Mykonos" finds the Pool Boy.
- No results: one line, "Nothing by that name. Try a hotel or a city.", and links to the four shirts.
