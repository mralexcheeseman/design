# Wordmark

The club's name set as type in the crest face: "OFF DUTY" over "HOTEL CLUB", centred.

- Markup: `<a class="odh-wordmark" href="/"><b>OFF DUTY</b><span>HOTEL CLUB</span></a>`. Add `on-dark` on `staff-green`.
- Use it once in the header (centred, links home) and once in the footer. Nowhere else.
- Keep both lines in capitals, in `ink` or `on-dark`. Never put it inside a crest, on a photo or in a hotel ink.
- There is no drawn logo or monogram yet. Don't make one up for a single page.
