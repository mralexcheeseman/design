# ColourDot

A 16px dot showing the shirt's garment colour on the product page.

- The consumer provides: the garment token and its name ("Rescue yellow").
- `radius-full`, filled with the `garment-*` token, with a 1px inset `line` so pale colours read on paper. The name follows in `body-sm`.
- It is information, not a control, while each role comes in one colour. If a role ever gets a second colour, it becomes a swatch control with a 1px `ink` ring when selected.
- Garment colours never appear anywhere else on the site.
