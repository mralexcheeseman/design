# HotelCard

One hotel: its number and place in the hotel's ink, the crest, the hotel's name, and a link to its uniform.

- The consumer provides: the hotel id (which picks the crest asset and the `hotel-*` ink), the number, the place and the name.
- The hotel's ink colours only the number line. The crest file already carries it. The name stays in `ink`.
- Lay the cards out on a hairline grid sharing borders: one row on desktop (four or five across), two on phones.
- Never put the crest on a coloured block or tint the card with the hotel colour.
