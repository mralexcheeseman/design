# Button

One button style: `label` type, 2px `ink` border, transparent fill, 44px tall, square corners. Hover fills with `ink`. The red variant (`.ew-btn-red`) is for the one primary action on a view. On night the border and text are `on-night`.

Everything else is a text link (`.ew-link`): inherits colour, 2px `red` underline.

**Never:** round the corners, add a drop shadow, or put more than one red button on a view.
