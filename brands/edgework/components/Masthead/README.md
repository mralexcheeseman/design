# Masthead

The `night` bar across the top of every page, `masthead-height` tall, sticky.

**Consumer provides:** the current route, so the matching item is marked.

**Rules**
- Left: "EDGEWORK" in `shout` at 28px with the letterpress mask, in `on-night`. It links home.
- Right: navigation as `label` in `on-night-2`: Positions, Essays, Dispatches, Work, About. The current item turns `red-night` with a 2px underline.
- On phones the nav collapses to a "MENU" label that opens a full-screen night sheet listing the same items at `shout` size.

**Never:** put marks or stains on the masthead, use icons for navigation, or add a second accent colour.
