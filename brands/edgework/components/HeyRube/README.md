# HeyRube

The full-bleed `night` band carrying the letterpress "HEY RUBE." lettering (`assets/marks/heyrube-letterpress.webp`, never re-set in a font) and one provocation beneath it in `type-lg`, `on-night`.

**Consumer provides:** the line, with an optional `*phrase*` for the highlighter.

**Rules**
- One per page at most. The lettering is an image: width 480px desktop, 280px phones, rotated -2°.
- The letterpress scan is red ink; show it as it is on the night ground. On paper use `heyrube-stamp.webp` instead.
- One splat mark may bleed in from an edge.

**Never:** typeset "HEY RUBE" in Anton or any font, or recolour the lettering.
