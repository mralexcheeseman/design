# Edgework components

Each folder has a README (what the consumer provides, the rules, what never to do) and, where it helps, a `preview.html` that `scripts/build-preview.mjs` puts on the brand's one-page view. Styles live in `bundle.css` and read `tokens.css`.

| Component | Used for |
| --- | --- |
| [Masthead](Masthead/README.md) | The night bar at the top of every page |
| [IndexCard](IndexCard/README.md) | A Position, typed on a ruled card and taped to the desk |
| [FileCard](FileCard/README.md) | An essay, filed as a manuscript with a folder tab |
| [Dispatch](Dispatch/README.md) | A published piece: headline that types itself on, deck, pull line |
| [HeyRube](HeyRube/README.md) | The letterpress "HEY RUBE." band, one per page |
| [Marks](Marks/README.md) | Coffee, ink, smudge, burn and tape scattered by seed |
| [TypedText](TypedText/README.md) | Word-jittered typewriter text with one highlighted phrase |
| [Scrawl](Scrawl/README.md) | The red-pen margin note |
| [Button](Button/README.md) | The one button style, and the text link |
