# Dispatch

A short published piece: a Hey Rube line, a dispatch, a routine script or an expense report, filed from Owl Farm.

**Consumer provides:** `format`, `title`, `deck`, `pull` (with one `*phrase*`), `body`, `published_on`, and a `seed`.

**Rules**
- In lists: the headline types itself on in `shout-sm` the first time it scrolls into view (`duration-key` per character, then a blinking cursor for 1.2s). Deck in `type`, `ink-2`.
- On its own page: a sheet at `measure` width, body in `type`, the pull line set in `type-lg` with the highlighter on its phrase, and one Scrawl in the margin on desktop.
- The format shows as a `label` stamp: DISPATCH, HEY RUBE, ROUTINE, EXPENSE REPORT, ESSAY.

**Never:** publish a dispatch that wasn't marked published in Owl Farm, or type on body text (only headlines type).
