# Merch and print

Edgework has no physical products. Its print-like outputs are exported images:

| Output | Size | Notes |
| --- | --- | --- |
| Social card (Dispatch, Hey Rube, Expense report, Essay cover) | 1080 × 1350 (`ratio-post`) | Exported from Owl Farm's Typewriter as PNG. 64px safe margin. |
| Routine reel | 1080 × 1920 (`ratio-reel`) | Storyboard and script from Owl Farm; MP4 rendered outside Base44. Keep text out of the top 220px and bottom 320px (platform UI). |
| Open Graph image | 1200 × 630 | Night ground, "EDGEWORK" letterpress, one splat. |

If a printed item is ever made (a zine, a poster), the marks must be printed from the full-size masters, not the web exports, and this file gets a proper print spec first.
