# Review checklists

Run every checklist that applies before calling work done, and name the ones you ran in your summary or PR. Brand-specific values (colours, names, sizes) come from that brand's `README.md`, `tokens.json` and `merch.md`.

| Work | Checklists |
| --- | --- |
| A page, component or layout change | [page](page.md), [copy](copy.md) |
| Copy only (product text, emails, social captions) | [copy](copy.md) |
| Product or campaign images | [photography](photography.md) |
| A crest, back print or any file a supplier will print | [crest and print](crest-and-print.md) |

An item that fails is fixed, or recorded in the brand's `decisions.md` as a deliberate exception with the reason.
