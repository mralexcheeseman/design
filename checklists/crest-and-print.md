# Crest and print review

For anything a supplier will print or stitch. Values are in the brand's `merch.md` and the `print` group of `tokens.json`.

## Crests
- [ ] Reads at 25% size, and still looks drawn by the same hand as the rest of the set.
- [ ] One ink; no gradients, shading or fills behind text.
- [ ] No line thinner than `crest-min-line`, no text below `crest-min-cap-height` (4.5mm if embroidered).
- [ ] Spelling and accents checked letter by letter.
- [ ] Viewed on the actual shirt colour, at full size.

## Files
- [ ] Outlined SVG (no live fonts) plus a transparent 300 dpi PNG, at final physical size.
- [ ] Ink colour matches the shirt's ink in `merch.md`; Pantone noted if it has been confirmed.
- [ ] Placement and size written in the order: crest position from the shoulder seam, back print width and distance below the collar.
- [ ] Fonts used are licensed for merchandise (SIL OFL fonts are).

## Before bulk production
- [ ] A physical sample was scored with the brand's scorecard (`SAMPLE-ORDER.md` in storefront-kit).
- [ ] Traced artwork has had a designer clean-up.
